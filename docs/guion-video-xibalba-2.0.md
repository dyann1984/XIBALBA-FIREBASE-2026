## 4. Preparación de grabación 1080p y lista de evidencias

### Configuración técnica recomendada (OBS / Playwright)
- **Resolución de lienzo:** `1920x1080`, `30 fps` o `60 fps`, formato `MP4 (H.264 / AAC)`.
- **Entorno limpio:** ocultar barras de marcadores, usar ventana incógnito con zoom al 100%, limpiar historial de demostración antes de iniciar (`Borrar historial`).
- **Demo automatizada grabada:** ver `artifacts/xibalba-2.0/xibalba-2.0-demo.mp4` (generado directamente desde una sesión real de Playwright + FFmpeg sobre el build de producción).
